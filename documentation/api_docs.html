🔌 Developer API Documentation

Integrate our QR Engine into any third-party software using our RESTful API.

POST /api/v1/generate

Required Parameters

ParameterTypeDescription
keyStringYour Secret API Key (found in Profile).
dataStringThe URL or text to encode.
styleStringOptions: square, circle, rounded, gapped.
fg_colorStringHex code (e.g., #ff0000).

Example Request (Python)

import requests

payload = {
    'key': 'YOUR_API_KEY',
    'data': 'https://example.com',
    'style': 'circle',
    'fg_color': '#000000'
}

response = requests.post('https://yourdomain.com/api/v1/generate', data=payload)
with open('qr_code.png', 'wb') as f:
    f.write(response.content)
