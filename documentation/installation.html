🚀 Quick Start Guide

Follow these steps to deploy QR Master Pro in under 5 minutes.

STEP 1 Upload & Environment

Extract the zip file to your server. Create a virtual environment to keep dependencies isolated:

python3 -m venv venv
source venv/bin/activate

STEP 2 Install Requirements

Run the following command to install Flask and all generation libraries:

pip install -r requirements.txt

STEP 3 Database Setup

Initialize your database schema and migrations:

flask db init
flask db migrate -m "Initial"
flask db upgrade
