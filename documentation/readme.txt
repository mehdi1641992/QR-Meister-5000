[DESCRIPTION]
A high-performance Flask-based SaaS for generating Dynamic QR Codes, 
Barcodes, and tracking real-time scan analytics with Geolocation.

[CORE FEATURES]
- Dynamic QR Engine: Update URLs after printing.
- 1D Barcode Engine: Support for EAN, UPC, and Code 128.
- Geo-Analytics: Track City, Country, and Device IP.
- B2B API: Token-authenticated API for developers.
- 16K Resolution: High-fidelity downloads for professional printing.
- Bulk Generator: Create and download up to 100 codes in a ZIP.
- Admin Dashboard: Manage users, transactions, and site content.

[TECHNICAL ASSETS]
- Backend: Python 3.10+ (Flask Framework)
- Database: SQLite (SQLAlchemy ORM with Naming Conventions)
- Frontend: Tailwind CSS, Phantome Icons, Leaflet.js (Maps)
- Migrations: Full Flask-Migrate / Alembic history included.

[FILE STRUCTURE]
/source_code    -> Core Python/Flask logic
/static         -> CSS, JS, and User Uploads
/templates      -> Modular HTML components
/migrations     -> DB schema versioning
/documentation  -> Guides and API Specs
